# Kronos Controller

Aplicativo de configuração da base de force feedback **Kronos K80x**.

## Baixar

Vá em **[Releases](../../releases/latest)** e baixe o arquivo `KronosController-Setup-<versão>.exe`.

- Windows 10 ou 11, 64 bits
- Instala sem pedir senha de administrador
- Gratuito, sem ativação e sem ficar preso a um computador

Na primeira execução o Windows pode mostrar o aviso *"O Windows protegeu o computador"*. Clique em **Mais informações** e depois em **Executar assim mesmo**.

## Atualizações

Depois de instalado, o programa procura versões novas sozinho ao abrir e instala com um clique. Seus perfis e os ajustes gravados na base não são alterados.

Este repositório guarda apenas os instaladores. O programa é construído sobre o [OpenFFBoard](https://github.com/Ultrawipf/OpenFFBoard) (licença MIT); os avisos de licença acompanham o programa.
